# Análisis de Factores Asociados al Rendimiento Estudiantil

## 1. Pregunta del Proyecto
¿Existe una relación positiva directa entre el número de horas de estudio y el índice de desempeño académico final, y cuál es el impacto de las notas previas y las actividades extracurriculares en dicho rendimiento?

## 4. Cómo ejecutar el notebook
1. Descargar el archivo principal `.ipynb` de este repositorio o del Campus Virtual.
2. Descargar el archivo de datos (`Student_Performance.csv`) desde el enlace de Kaggle provisto arriba.
3. Abrir el archivo en **Google Colab** o Jupyter Notebook.
4. Cargar el archivo CSV en el entorno de trabajo.
5. Ejecutar todas las celdas en orden secuencial para ver los resultados y gráficas.
